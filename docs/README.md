## 文档撰写与维护规范

1. **真实事实优先**：所有结论必须附带可复现的命令、测试输出、响应耗时或源码类名与行号支持。
2. **术语与版本精确**：明确记录运行环境与依赖版本（如 `ILS 271.2085.0`、`JBR 25`、`Gradle 9.8.0`、`adblib 9.4.1` 等），不使用含糊指代。
3. **去包装化**：严格遵循说人话规范，不使用 AI 营销词与无信息量的套话，突出“问题现象 → 根因排查 → 解决方案 → 对比数据”。
